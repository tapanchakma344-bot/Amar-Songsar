# আমার সংসার — Android starter

এটি একটি প্রাথমিক Android Studio প্রজেক্ট। এতে বাংলা UI, আয়/খরচ যোগ করা, আয়-ব্যয়ের সারাংশ এবং ফোনে স্থানীয়ভাবে হিসাব সংরক্ষণের ভিত্তি আছে।

## চালানোর নিয়ম
1. Android Studio (Giraffe বা নতুন) খুলুন।
2. `amar_songsar_android` ফোল্ডারটি Open করুন।
3. Gradle Sync শেষ হলে Emulator বা Android ফোনে Run চাপুন।

## বর্তমান সংস্করণের সীমাবদ্ধতা
- এই প্রাথমিক build-এ হিসাব শুধু বর্তমান ফোনে সংরক্ষিত হয়।
- পরিবারের একাধিক ফোনে একই হিসাব দেখা, সদস্য লগইন, Cloud Sync/Backup, মাসভিত্তিক রিপোর্ট, সম্পাদনা/মুছে ফেলা এখনো যুক্ত হয়নি।
- Cloud ব্যবহারের জন্য Firebase project, Authentication এবং Cloud Firestore সেটআপ করে পরবর্তী ধাপে যুক্ত করতে হবে। পরিবারের ডেটা আলাদা রাখতে householdId-ভিত্তিক নিরাপত্তা নিয়মও লাগবে।
- বাস্তব ব্যবহারের আগে ব্যাকআপ, অ্যাকাউন্ট নিরাপত্তা ও ডেটা রিকভারি পরীক্ষা করা প্রয়োজন।

## পরবর্তী ধাপ
Firebase-ভিত্তিক পরিবার তৈরি/যোগদান, সদস্যের ভূমিকা, অফলাইন-অনলাইন Sync, এবং মাসিক রিপোর্ট যোগ করা।
